# STEP08: 3D 바닥판 면내강성 민감도

> 아래는 초기 1×1 메시 결과이다. 이후 수행한 전 층 변형·메시 세분화·고차 모드 추적 결과는 [STEP08 검증 보강](STEP08_검증보강.md)을 참조한다. 특히 양 끝 형상 대응과 연속 모드 추적을 구분해야 한다.

## 목적

대칭 3D 골조에서 바닥판의 면내강성을 변화시키고, 층 안에서 절점들이 서로 얼마나 다르게 움직이는지와 고유모드가 어떻게 변하는지 확인한다. 질량편심은 0으로 고정했다. 이 단계의 결과는 지진 시간이력 응답이나 실제 건물의 설계 판정이 아니다.

## 비교 모델과 가정

골조는 STEP07의 3층, X방향 3경간 × Y방향 2경간 모델이다. 부재 단면, 강접합, 고정기초, 층당 200 kN의 가정 중량, 골조 절점 12개에 균등 배분한 수평질량, 중력 선행해석과 기둥 PDelta 변환을 모든 경우에 동일하게 사용한다. 바닥판에는 질량과 중력하중을 추가하지 않는다. 질량중심은 각 층 평면의 중심이다.

| 조건 | OpenSees 구현 | 가정한 셸 탄성계수 E (kN/m²) |
|---|---|---:|
| 강체 | `rigidDiaphragm(3, ...)`와 `Transformation` 구속 | 해당 없음 |
| 반강체 | 경간마다 `ShellMITC4` + `ElasticMembranePlateSection` | 2×10⁷ |
| 유연 셸 | 같은 셸 연결과 요소, 더 작은 E | 2×10⁴ |
| 강체 극한 확인 | 같은 셸 연결과 요소, 매우 큰 E | 2×10¹⁰ |
| 보 격자만 | 셸을 제거한 하한 대조군 | 0 |

셸 두께 0.12 m, 포아송비 0.20은 모두 **연구자가 가정한 값**이다. `E·h`가 면내 인장·전단강성의 크기를 결정하며, 등방성 평면응력의 막강성은

\[
\mathbf D_m=\frac{Eh}{1-\nu^2}
\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&(1-\nu)/2\end{bmatrix}
\]

이다. 요소의 면외 휨강성 수정계수는 0으로 두어, 비교 중에 바닥판 면외 휨강성이 함께 변하지 않게 했다. 골조 보의 강성과 축강성은 모든 경우에서 그대로 유지한다. 현재 셸 메시의 한 칸은 6×6 m이고, 메시 수렴 검증은 아직 하지 않았다.

강체 조건에서 각 층 절점은 `u_x = U_x - y R_z`, `u_y = U_y + x R_z`를 만족한다. 유한강성 조건에서는 이 관계를 강제하지 않고 셸 막요소가 전달하는 면내 힘으로 절점 운동이 결정된다.

## 측정 방법

1. 각 모델에서 동일한 중력하중을 가하고 기초 반력, 총 질량, 질량중심을 검사한다.
2. 지붕층 각 절점에 합계 12 kN인 X방향 또는 Y방향 수평하중을 균등하게 가한다. 중력 평형의 변위를 빼고 추가 수평하중에 의한 변위만 측정한다.
3. 지붕 절점의 최대·최소 수평변위 차이와, 최적의 강체평면 운동을 제거한 잔차의 RMS를 층 내 변형 지표로 사용한다.
4. 강체 모델은 9개, 유한강성 모델은 24개 고유모드를 추출한다. 질량 절점의 X/Y 모드성분을 질량 정규화하고, 질량가중 MAC으로 강체 기준 모드와 대응시킨다. 모드 순번만으로 비교하지 않는다.
5. 지붕 모드의 강체평면 운동을 제거한 잔차 노름을 전체 지붕 모드 노름으로 나눈 값으로 모드의 면내 왜곡률을 구한다. 이는 실제 변위 진폭이 아니다.

## 계산 결과

| 조건 | 지붕 X하중 면내 왜곡 RMS (mm) | 지붕 Y하중 면내 왜곡 RMS (mm) | 1차 주기 (s) | 2차 주기 (s) |
|---|---:|---:|---:|---:|
| 강체 | 0 | 0 | 0.331977 | 0.306680 |
| 반강체 | 0.000094 | 0.000058 | 0.331979 | 0.306690 |
| 유연 셸 | 0.000446 | 0.000287 | 0.331987 | 0.308981 |
| 보 격자만 | 0.000448 | 0.000289 | 0.331987 | 0.311608 |

큰 강성의 셸 모델은 강체 구속 모델의 주기와 모드형상에 수렴했다. 셸을 약하게 만들면 정적 하중 아래 지붕 절점의 상대운동이 커진다. 단, 값은 층 전체 이동량 약 0.74 mm에 비해 작다. 그 이유는 기존 X/Y 보 격자가 바닥판과 별개로 절점들을 연결하기 때문이다. **`유연 셸`은 셸의 가정 면내강성이 작은 조건이라는 뜻이며, 골조까지 포함한 전체 층이 크게 변형하는 ‘유연 다이어프램’으로 검증됐다는 뜻은 아니다.** 셸을 완전히 제거한 `보 격자만` 결과는 이 골조에서 바닥판 셸 강성 0의 정적 변형 상한을 보여준다.

반면 고차 비틀림 모드는 더 민감하다. 강체 모델의 5차 모드와 대응되는 유연 셸 모드는 전체 순번이 9차로 바뀌고, 주기는 약 6.8% 증가한다. 지붕 모드형상의 면내 왜곡률은 약 44.8%, 질량가중 MAC은 약 0.807이다. 1차 병진모드의 주기가 거의 같다는 이유만으로 모든 모드형상이 같다고 판단할 수 없다. 강체 기준 8차와 대응되는 유연 셸 모드는 16차가 되므로 모드 순번의 직접 비교는 특히 위험하다.

## 해석의 한계와 후속 검증

현재 `반강체`와 `유연 셸`의 E는 특정 슬래브·데크·연결부에서 산정한 값이 아니다. 바닥판 요소는 경간당 하나인 거친 메시이므로, 최종 연구 결과에 사용하기 전 메시 민감도와 실제 바닥판 유효강성 산정이 필요하다. 보 격자의 면내 구속을 별도로 계산하고, 전체 구조의 층 내 변형비에 따라 ‘유연’이라는 분류를 다시 판단해야 한다. 이번 단계에는 질량편심, 비선형 재료, 지진 시간이력은 포함하지 않았다.
